# IHP 固定候选有限对照与消融（2026-10-04）

此报告是首轮历史消融结果，解析方式和采样条件与后续双工艺研究不同。选定汇总随补充附件提供，原始候选响应和完整物理证据未随精简包分发。

固定7任务，49次真实新token续写，候选预算2/4/1、种子17、128token，温度0.2/top_p0.9。任务不筛选，分母7任务/21意图槽；所有组采用同一官方规则、候选选择器、图层映射、KLayout0.30.7与现有Python。模板、修复和回退使用已验收delta20构造。生产初始delta100不再用于追加反馈或迭代。

解析结果四个模型组共享7/49成功、42/49失败，7返回均几何合法且全为BAD；固定选择后4/21槽有原始图。其余17槽是无可用响应，计失败而非非法拒绝。纯模板无响应解析环节。详见FINAL_COMPARISON.json、COMPARISON.csv、PER_TASK.json和after03/CASE_REVIEW.json。

独立开关真实生效：关闭修复跳过adjust_llm_cases，包括IHP强制可信模板替换；关闭回退仅保留已解析候选的修复，不补缺失。原始模型两者均关闭，测试以禁止函数调用证明没有隐式模板生成/修复。现有生产llm_repair耦合两者，force_template_bad不能控制IHP契约路径，故采用独立离线入口，生产默认及工艺保护保持。完整混合21图与旧repair_smoke逐点/标签相同。

修复使4个BAD图形改变：NW.a、Rsil.f原始BAD已有非空正确输入、自身分别命中2，修复未增加它们的目标成功；Gat.f缺GatPoly，Gate.ext_not(SVaricap)=0；npn13G2L.b缺TRANS、E引脚和器件文字，emit_npn13G2L=0。后两项由修复补齐实际分支，目标对由5/7变7/7。关闭回退仍能修复4个BAD，但7个GOOD全部缺失，目标对仍0/7。回退补17槽（7GOOD、3BAD、7ILLEGAL）；ILLEGAL成功来自模板非法图，不能称原生模型拒绝成功。

纯模板与完整混合本集合目标对均7/7，混合未显示新增覆盖。来源完整混合为17回退/4修复；来源数不等于贡献。原始模型本集合有效BAD为2/7、有效目标对0/7，而不是“模型完全没有正确图”。各组BAD目标计数与有效BAD在本集合相同，仍分别保留输入证明。

其他命中保留：模板/混合M1.c BAD的Cnt.h:1、M1.c1:1沿用旧独立联动证据；原始Gat.f BAD另命中Act.d:1。关闭修复保留两类，关闭回退仅有修复后的四BAD且无其他命中，但不能据此称整体更好，因为17槽缺失。其他命中不混入自身目标分数，也不一律称不可避免。

旧物理证据复用14个合法图，完整点列/标签/几何允许条件、官方行号/表达式、固定规则/引擎/动态库/参数同源。4个不同的原始图做新官方DRC、原生逐顶点核对及真实派生输入测量；7个解析返回中重复图均精确映射到这4个物理结果，无未核对的成功原始候选。预算保守计4个官方DRC+4个输入测量=8/60图，累计10.014/1800秒。新模型调用0；49次原调用共享复用一次，逐调用计时合计222.683秒，原混合进程墙钟283.462秒（含DRC与流程开销），不乘四、不当成本轮新消耗。离线各组构造约0.0001至0.009秒，仅单次描述值，不做性能胜负推断。

优先根因：
1. 结构化响应与示例复述：27次无JSON、9次字符串截断、6次缺lpl；7次成功续写均复述400×160nm的output_schema示例。它们确实来自新token续写，并非评测器拿prompt代替输出；成功解析不等于理解规则。输出约束和示例设计仍需要独立实验检验。
2. 复杂域/文字上下文缺失：Gat.f与npn13G2L.b即使原始几何合法也缺真实目标域。优先验证模型是否能输出必要伙伴层、载体和文字；仅检查单层bbox或目标0无效。阵列Cnt.b1本轮无原始候选，不能从回退成功推断其模型能力。
3. 保守修复过度替换：两个已正确简单BAD仍被可信模板等价门槛替换。未来可研究带独立物理/输入证明的保留门槛，以减少无目标收益的替换；本轮不放松保护，不以这两项外推其他规则安全性。

结论仅回答这批固定候选上的组件改变，不能推广到全规则、其他采样、反馈增长、训练或完整闭环因果贡献。原始模型缺GOOD不代表更大采样预算仍必然失败。本次历史消融没有新增全量推理、SKY全量DRC、训练或跨引擎检查；对应版本238测试通过。中间失败、冻结副本和原证据保留于完整归档，本研究不能替代最新整体验收及旧封存。
